## How to Capture and Save Your Session Screenshots

1. In **Bob IDE**, open the **Tasks** panel in the chat sidebar.
2. Select an active or completed task (e.g. `Task 01: Invariant Miner Scaffolding`).
3. Click the task header to view the **Session Consumption Summary** (showing Bobcoins burned, tokens used, and tool calls).
4. Take a clear screenshot of the entire summary.
5. Save the file in this directory (`bob_sessions/`) as a **PNG** using the standard naming format:
   `mrsage_task<XX>_<task_name>_summary.png`
